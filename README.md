# Tenghan Zhong's academic website

Source for [tenghanzhong.github.io](https://tenghanzhong.github.io/).

## Content

- `_pages/about.md`: research papers, projects, experience, and education.
- `assets/papers/`: downloadable paper PDFs.
- `assets/Tenghan_CV.pdf`: curriculum vitae.
- `_data/navigation.yml`: section navigation.
- `_config.yml`: site identity and configuration.

## Local preview

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000/`. GitHub Pages builds the published site from `main`.
