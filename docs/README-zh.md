# Tenghan Zhong 个人学术主页

网站地址：https://tenghanzhong.github.io/

## 内容维护

- 主页与论文列表：`_pages/about.md`
- 论文 PDF：`assets/papers/`
- CV：`assets/Tenghan_CV.pdf`
- 导航：`_data/navigation.yml`
- 网站配置：`_config.yml`

安装 Ruby 与 Bundler 后，运行 `bundle install` 和 `bundle exec jekyll serve`，在 `http://127.0.0.1:4000/` 本地预览。GitHub Pages 从 `main` 构建公开网站。

本站使用 Yi Ren 的 [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) 模板，并保留相关项目的版权及许可证说明。
